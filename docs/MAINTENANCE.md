# 持续维护 / Ongoing maintenance

## 中文

本项目将持续维护，并根据使用反馈不定期更新。当前为 Beta 测试版，重点是完善组件、修复交互问题、提高旧项目分类导入质量，以及保持 SwiftUI / Compose / Flutter 源码导出和 MCP 的一致性。

- 问题与组件需求：提交 GitHub Issue，注明版本、系统、导出格式、复现步骤和最小示例。
- 更新获取：关注 Releases；每次发布记录变更和验证范围。
- 升级：下载新版编辑器替换应用，保留设计文件；重连已运行的 MCP 服务。
- 兼容性：设计格式变动会在更新日志中说明；重要设计应保留副本。
- 更新节奏按实际修复和功能进展安排，不设固定发布日期。

## English

The project will continue to be maintained and updated in response to usage and feedback. This Beta focuses on component coverage, interaction fixes, better source import classification, and consistency across SwiftUI / Compose / Flutter exports and MCP.

- Report bugs or component requests through GitHub Issues with version, OS, export format, reproduction steps and a minimal example.
- Follow Releases for updates. Each release will describe changes and the validation performed.
- Replace the editor application when upgrading, keep design documents, and reconnect running MCP servers.
- Design-format changes will be documented in the changelog. Keep copies of important designs.
- Updates will ship as fixes and features are ready; there is no fixed release schedule.

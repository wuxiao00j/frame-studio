# 原境 Beta 使用指南

## 安装与保存

下载 GitHub Beta Release 的 macOS-arm64 ZIP，解压后将 `原境 Frame Studio.app` 放到“应用程序”。需要 Apple Silicon 与 macOS 14 或更新版本。Beta 使用临时签名，尚未进行 Developer ID 公证；不便运行下载包时，可以在 Xcode 打开 Package.swift 或使用构建脚本。

首次打开会创建通用示例，默认设计文件位于 `~/Library/Application Support/FrameStudio/Workspace.framestudio`。修改自动保存，项目菜单提供新建、打开、另存为。更新应用前，建议给重要设计另存一份；安装包不会替换设计文件。

## 编辑页面

1. 左侧页面加号添加页面，右键复制或删除页面。
2. 点击或拖动组件到手机画布。直接点选组件编辑属性；Tab / 侧栏可从“图层”中选择，以免触发页面跳转。
3. 拖动组件移动位置；右下角紫色箭头调整宽高，Shift 保持比例。
4. Shift 点击多选。对齐工具提供左、中、右、顶、中、底对齐，至少三个组件可等距分布。拖动显示吸附参考线。
5. 右侧编辑文字、图标、颜色、边框、阴影、间距和圆角。圆角可以拖动滑块，也能输入数值。HEX 输入完成后回车应用。
6. ⌘Z 撤销，⇧⌘Z 重做，⌘D 复制，⌘⌫ 删除选中组件。

Beta.4 修复了选中组件后点击坐标输入框的闪退。可直接编辑 X、Y、W、H，回车或移开焦点提交；无效尺寸会回退，⌘Z 可撤销。

## 长页面与两种屏幕形态

未选中图层时，右侧“长页面滚动”可调整内容高度、开启上下滚动。超出一屏的内容自动扩展。将光标放在手机内部滚动。

导航栏与 Tab 默认固定，也可以为任意组件切换“固定在屏幕上”。顶部提供“标准屏”和“阔屏”；阔屏并排显示内外屏，两类均可切换横竖方向。内容共享，六套布局坐标独立保存。尺寸是可编辑设计单位，不是具体机型的官方分辨率。

## 组件属性与图标

- 开关、独立开关、复选框与单选按钮支持左右排列，文字与前置图标可选。
- 进度可选条形、环形、分段，显示百分比或当前数 / 总量，并调整粗细和颜色。
- 资料栏可以隐藏二维码和箭头，或分别上传替换图标。
- 连续添加列表行会自动紧贴，连接处去掉圆角，只保留外侧圆角。页面属性可关闭自动拼接。
- 上传本地图片后会保存到设计中，随源码导出为 PNG；系统图标选择仍然可用。
- Tab 每一项都能设置默认、选中图标，选择系统图标或上传图片，通过“上移 / 下移”调整顺序。项目内所有已有 Tab 栏共用全部配置，包括项目增删、名称、目标页面、图标、颜色、圆角、字体、间距、显隐、锁定及各屏幕的位置尺寸。编辑任意一处自动同步；没有 Tab 的页面不会自动添加，后来添加的 Tab 会继承现有配置。每个页面仍高亮自己的对应项。
- 点击添加返回按钮时默认位于左上角（X=16、Y=52，避开状态栏），默认固定；仍可拖动或改为随页面滚动。导航栏拆分出的返回按钮保留原位置。返回使用原型页面访问历史。

打开有差异的旧设计时，以页面顺序中的第一个 Tab 栏统一配置；读取本身不覆盖原文件，下一次编辑保存时写入统一结果。六种屏幕布局仍各自独立，只同步页面之间的同一种布局。

选中组件后，在“渐变与柔化”中启用渐变，修改各色标颜色、线性方向或径向半径；可以调整模糊和阴影颜色、偏移。底层固定背景会保持在内容后方。不同宽度采用不同 ViewThatFits 分支时，画布只显示当前布局对应的图层。

## 裁剪、文字、图片与材质

Beta.7 保留矩形、圆角矩形、圆形 / 椭圆和胶囊的嵌套裁剪，横竖屏独立存储。裁剪边界随拆分图层移动、缩放；选择图层后可在“导入的容器裁剪”中解除，并用撤销恢复。任意自定义 Path、渐变透明度蒙版和组合级混合效果仍需人工还原。

文字组件新增“文字排版”：限制行数、行间距和最小字号比例。图片组件新增“图片显示”：填满裁剪、完整显示或拉伸。导入器展开支持的 Text / View 扩展修饰器链，保留这些规则，并修正主题条件颜色与中文多行测量。

“渐变与柔化”的“背景材质”提供五档磨砂。Mac 预览和 SwiftUI 源码使用系统 Material，Flutter 使用背景模糊；Android Compose 使用半透明底色替代，导出报告会说明差异。它们不等同于完整的系统 Liquid Glass 折射与交互动画，静态 PNG 也不能完整反映实时材质。系统字号偏好、未提供的运行状态和复杂布局仍需对照目标设备。

## 创建自己的组合

Shift 多选基础图层，点击组件库顶部“创建组合”，输入名称保存。之后点击组件库中的组合即可再次插入。

资料栏、列表、卡片、导航、开关、按钮等预置组合可以“拆分为基础组件”。拆开后自动解除组合，直接点击就能逐个修改文字、图标、背景与控件，位置和尺寸保留。编辑后 Shift 多选，点击右侧“合并组件”或 ⌘G；“拆分组合”或 ⇧⌘G 可再次解组。右键菜单也提供这些操作。需要复用时再命名保存为组件模板。自定义代码组件可分别提供 SwiftUI、Compose 和 Flutter 表达式；编辑器不执行这些代码。

## 导入旧 UI

项目菜单“导入旧 UI 项目”选择源文件或目录。SwiftUI 项目建议选择包含所有 View、主题和资源的项目目录，以便跨文件展开复用组件。分析完成后选择新的 `.framestudio` 保存位置，当前设计会保留，避免两个项目的 Tab 配置混合。

SwiftUI 按 View 声明读取：数据 Store、属性包装器、模型和事件处理函数不生成页面；源码中的自定义组件会尽量展开，常用的 VStack / HStack / ZStack、padding、frame、字体、颜色、圆角、线性 / 径向渐变和模糊按各自作用范围转换。Tab 目标页和弹窗作为页面，其他复用组件进入组件库。Flutter、Compose、JSX / HTML 保留原有基础分类方式。

报告分为“组件与复用”“未匹配视图”“待还原”和“导入说明”。**没有未匹配视图，不等于画面完全还原。** 动态文案、登录状态、服务端数据、主题计算、复杂自定义布局、系统材质和未支持修饰器仍可能需要 Agent 对照源码或原 App 画面补充。动态列表可能使用一个样例或源码中声明的默认顺序。未知颜色使用中性占位色，未知图片保留图片占位。

导入不会运行或修改原代码，也不会读取原 App 的登录数据。请用原 App 的目标主题和状态作为视觉对照，再逐项调整“待还原”内容。

## 导出给开发者

点击右上角“导出代码”，选择 SwiftUI、Android 原生 Compose 或 Flutter，再选择目录。每次创建新目录，保留旧导出。

导出包含页面源码、资源、项目配置、`Design.framestudio`、`UI_HANDOFF.md` 和 `export-manifest.json`，**没有手机安装包**。项目配置用于接入开发流程，原型交互不是已完成的业务功能。开发者需继续实现真实状态、服务、登录、支付、数据、异常和正式发布。

SwiftUI 用本地 Swift Package 或源码集成；Compose 使用导出的 Kotlin 页面和资源；Flutter 使用 Dart 页面和 assets。请先阅读导出目录中的说明和平台差异报告。

## Beta.8 表单与选项

本次补齐 SwiftUI 表单导入：识别无关联值枚举的 allCases、rawValue 与静态标签，读取 State(initialValue:) 默认状态，解析常见布尔组合和空值回退。修正选项显示变量名、选中状态丢失、错误展示条件提示的问题。

Form / Section 保留常见分组卡片、标题、内边距和行分隔线；顶部导航标题与左右工具栏按钮转换成可编辑图层。多行输入按 axis 转换，新增“手机表单行”样式、默认选项与“启用交互”属性；日期值可使用 Agent 提供的运行对照值。简单 dismiss() 转换为原型返回，保存等业务处理不会执行或自动实现。

新增属性同步至 Mac 预览、SwiftUI、Compose、Flutter 源码和 MCP。复杂自定义表单、未提供的日期或运行状态、平台字体与系统玻璃效果仍需对照调整。


## Beta.9 分类与跨项目复用

本次完善组件复用：新增 7 个通用内置组合，涵盖手机表单文本行、日期行、选择行、多行备注、提醒双选项、分组卡片和弹窗导航。它们使用通用示例内容，可在所有项目中插入，不包含个人项目数据。

组件库按分类展示内置组合、个人组件和项目组件，支持搜索名称与分类。保存组合时可填写分类，并勾选保存到个人组件库；以后新建或打开其他项目即可复用。已有项目模板可右键保存到个人库或更改分类。相同模板再次保存到个人库会更新其副本。

个人库保存在本机，保留六套布局、图标、渐变、裁剪和表单属性；插入时生成独立图层，并清理目标项目中不存在的页面链接。库写入有版本冲突检查与原子保存。MCP 共 28 个工具，新增分类和内置模板元数据。旧模板没有分类字段时自动显示建议分类。导出仍只生成 UI 源码。

# 原境 Beta 使用指南

## 安装与保存

下载 GitHub Beta Release 的 macOS-arm64 ZIP，解压后将 `原境 Frame Studio.app` 放到“应用程序”。需要 Apple Silicon 与 macOS 14 或更新版本。Beta 使用临时签名，尚未进行 Developer ID 公证；不便运行下载包时，可以在 Xcode 打开 Package.swift 或使用构建脚本。

首次打开会创建通用示例，默认设计文件位于 `~/Library/Application Support/FrameStudio/Workspace.framestudio`。修改自动保存，项目菜单提供新建、打开、另存为。更新应用前，建议给重要设计另存一份；安装包不会替换设计文件。

## 编辑页面

1. 左侧页面加号添加页面，右键复制或删除页面。
2. 点击或拖动组件到手机画布。直接点选组件编辑属性；Tab / 侧栏可从“图层”中选择，以免触发页面跳转。
3. 拖动组件移动位置；右下角紫色箭头调整宽高，Shift 保持比例。
4. Shift 点击多选。对齐工具提供左、中、右、顶、中、底对齐，至少三个组件可等距分布。拖动显示吸附参考线。
5. 右侧编辑文字、图标、颜色、边框、阴影、间距和圆角。圆角可以拖动滑块，也能输入数值。HEX 输入完成后回车应用。
6. ⌘Z 撤销，⇧⌘Z 重做，⌘D 复制，⌘⌫ 删除选中组件。

## 长页面与两种屏幕形态

未选中图层时，右侧“长页面滚动”可调整内容高度、开启上下滚动。超出一屏的内容自动扩展。将光标放在手机内部滚动。

导航栏与 Tab 默认固定，也可以为任意组件切换“固定在屏幕上”。顶部提供“标准屏”和“阔屏”；阔屏并排显示内外屏，两类均可切换横竖方向。内容共享，六套布局坐标独立保存。尺寸是可编辑设计单位，不是具体机型的官方分辨率。

## 组件属性与图标

- 开关、独立开关、复选框与单选按钮支持左右排列，文字与前置图标可选。
- 进度可选条形、环形、分段，显示百分比或当前数 / 总量，并调整粗细和颜色。
- 资料栏可以隐藏二维码和箭头，或分别上传替换图标。
- 连续添加列表行会自动紧贴，连接处去掉圆角，只保留外侧圆角。页面属性可关闭自动拼接。
- 上传本地图片后会保存到设计中，随源码导出为 PNG；系统图标选择仍然可用。
- Tab 每一项都能设置默认、选中图标，选择系统图标或上传图片。默认同步到其他页面绑定同一目标页面的 Tab；可关闭同步。
- 返回按钮及导航栏“返回上一页”使用原型页面访问历史。

## 创建自己的组合

Shift 多选基础图层，点击组件库顶部“创建组合”，输入名称保存。之后点击组件库中的组合即可再次插入。

资料栏、列表、卡片、导航、开关、按钮等预置组合可以“拆分为基础组件”。拆开后可以取消组合，逐个修改文字、图标、背景与控件，再保存成新的组合。自定义代码组件可分别提供 SwiftUI、Compose 和 Flutter 表达式；编辑器不执行这些代码。

## 导入旧 UI

项目菜单“导入旧 UI 项目”支持 SwiftUI、Flutter、Compose、JSX / HTML 等源文件或目录。报告列出组件分类、未匹配预设和导入说明。

静态识别得到的是可编辑草稿。复杂动态布局、业务状态和导航仍需由开发者或 Agent 对照源代码还原。没有匹配的组件会保留名称和源码位置，不会假装已完整实现；可据此反馈需要新增的预设。

## 导出给开发者

点击右上角“导出代码”，选择 SwiftUI、Android 原生 Compose 或 Flutter，再选择目录。每次创建新目录，保留旧导出。

导出包含页面源码、资源、项目配置、`Design.framestudio`、`UI_HANDOFF.md` 和 `export-manifest.json`，**没有手机安装包**。项目配置用于接入开发流程，原型交互不是已完成的业务功能。开发者需继续实现真实状态、服务、登录、支付、数据、异常和正式发布。

SwiftUI 用本地 Swift Package 或源码集成；Compose 使用导出的 Kotlin 页面和资源；Flutter 使用 Dart 页面和 assets。请先阅读导出目录中的说明和平台差异报告。
